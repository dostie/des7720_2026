# DES7720 - Atelier de design d'expériences interactives 1 (partie 2)

Ce repo documente les expérimentations dans le cadre du cours DES7720 - Atelier de design d'expériences interactives 1 donné par le professeur Junior Vigneault à l'automne 2026.

Thème de la partie 2: **le code comme matière**. Le code (p5.js) sert à fabriquer, observer et réfléchir. Chaque version est une hypothèse de design, chaque commit en explique l'intention.

## Structure

| Dossier | Contenu |
|---|---|
| `journal/` | Un fichier par séance (intention, changements, effets, accidents, prochaine piste) |
| `experiences/` | Les expérimentations p5.js: un dossier par expérience (`exp-XX_nom/`, avec son README) et un dossier par cours (`cours_N/`) pour les exercices donnés par Junior, gardés tels que fournis puis travaillés avec des commits |
| `projet/01_video/` | Prototype vidéo (10 %) |
| `projet/02_interactif/` | Prototype interactif final (20 %) |
| `projet/03_tests/` | Observations et réactions lors des tests |
| `processus/` | Matériau du document de processus et bilan réflexif (20 %) |
| `docs/` | Plan de cours résumé, calendrier, évaluation, conventions |
