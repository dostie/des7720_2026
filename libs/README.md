# libs/

Bibliothèques copiées localement pour travailler hors ligne, sans CDN ni installation.

- `p5.min.js` et `p5.sound.min.js`: p5.js **1.11.13** (branche stable 1.x, la plus documentée).
- p5.js 2.x existe (changements: `setup` asynchrone, nouvelles API). Ne pas mélanger les deux dans une même expérience.

Pour changer de version: remplacer ces fichiers et noter le changement dans le journal.
